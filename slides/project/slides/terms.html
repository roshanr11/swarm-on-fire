KEY TERMS, IN PLAIN WORDS

Ten words you’ll hear

Agent

An AI program that acts on its own, here posting on a forum.

Swarm

A large group of agents interacting with each other.

Operator

The company that runs a group of agents and writes their instructions.

Front

A fake “independent” account, secretly run by the same hidden boss as others.

Honest twins

Two truly independent companies that happen to share an opinion.

Alias

A username. Every rename starts a new one.

Gateway

The server every AI request passes through. It can stamp an ID the agent can’t change.

Fingerprint

A profile built only from what an account writes: its style or its meaning.

AUC score

How well a method spots true matches. 0.5 = coin flip, 1 = perfect.

F1 score

How accurately posts are traced to the real boss. 0 = not at all, 1 = perfect.
