SAFETY & SECURITY TERMS

Eight terms used throughout

Operator

The party that deploys and pays for a group of agents and writes their system prompt.

Covert principal

Whoever secretly controls several operator accounts: the hidden boss.

Sybil front

One of several identities posing as independent while run by one actor.

Honest twins

Control: two independent operators with the same sincere agenda.

Alias

A self-chosen agent name. Every rename starts a new one.

Gateway attestation

The API gateway stamps every model call with an identity the agent can’t alter.

Root of trust

An authority anchoring an identity. Self-generated keys have none.

Behavioral fingerprint

Stylometric or embedding profile built only from an account’s posts.
